
# El Sombrero Seleccionador de Hogwarts

## Descripción del proyecto

Este proyecto es un juego interactivo desarrollado en Python utilizando Tkinter.

El objetivo es responder una serie de preguntas para descubrir a qué casa de Hogwarts pertenece cada jugador, según sus respuestas y puntuaciones.

## Tecnologías utilizadas

- Python
- Tkinter
- Messagebox

## Características del juego

- Registro del nombre del jugador.
- Preguntas con diferentes opciones de respuesta.
- Sistema de puntuación según las respuestas.
- Clasificación automática en las cuatro casas.
- Visualización del resultado final.
- Lista de todos los jugadores y sus resultados.
- Opción para volver a jugar.

## Las cuatro casas de Hogwarts

- Gryffindor
- Ravenclaw
- Hufflepuff
- Slytherin

## Cómo ejecutar el proyecto

1. Instalar Python en la computadora.
2. Descargar o clonar este repositorio.
3. Abrir una terminal dentro de la carpeta del proyecto.
4. Ejecutar el siguiente comando:

```bash
python main.py
```
